# Admin responsiveness and Devanagari font — synthetic QA

This run revisits the admin overflow and missing-glyph findings in `qa-evidence/product-workflows-2026-11-07/` using a new, isolated loopback-only PostgreSQL 18.6 cluster seeded with fictional demo records. Chromium 153 + Playwright use `--no-sandbox`, so this is not a browser-security evaluation. The test harness depends on separately installed local QA tools and hard-checks the database path and name before connecting; it is not intended for any real or shared environment.

**Results:** `results.json` records document widths and scrollable table sizes. At 320, 375, 768 and 1280 px the admin document did not overflow; narrow tables remained in a focusable horizontal scroll region, and ArrowRight moved that region at 320 px. In Hindi and Marathi at 375 px the locally served Noto Sans Devanagari font was loaded by the browser, text rendered rather than missing-glyph boxes, and the document did not overflow. Screenshots are fictional demo content. The viewport sweep is limited to these sampled states; it does not establish cross-browser/device, WCAG, screen-reader or native-speaker translation acceptance. The historical failing screenshots remain unchanged as before-fix evidence.

The vendored WOFF2 is Noto Sans Devanagari v30 (Fontsource variable Devanagari subset, package 5.3.0); its SIL OFL 1.1 notice is included at `web/public/licenses/NotoSansDevanagari-OFL.txt`. No patient record, clinical authorization, consent, migration or production environment was changed as part of the product fix. DW-P0-01/02 remain open; A-3.2 remains not accepted pending complete language/accessibility review.
