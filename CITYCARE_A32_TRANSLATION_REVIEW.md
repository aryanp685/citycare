# CityCare A-3.2 — Hindi and Marathi translation review package

**Status: awaiting qualified human review; no translation is approved.** Source: current `web/src/lib/i18n.ts`. This is a conservative superset: every records/documents catalog keys (210), plus both shared language-switcher keys and two policy-sensitive retention variants carried over from the earlier foundation/privacy correction (214 rows). It includes keys reused in print and may include keys that are not currently rendered. The retention variants are included for continuity even though the privacy notice is a linked page outside this records route; other pre-existing legal-page text and independent workflows are excluded. The catalog was introduced in the working tree, so the package does not imply each key originated in a particular substep. Placeholders such as `{count}` and `{date}` must be retained. Clinical source names, values, units, original document contents and user-entered text are not intended translation targets. Existing observations have no name-provenance marker: stored reading names, including values identical to a predefined option, are displayed without translation. Only the application-owned selector captions use the predefined trend translations. No stored text is changed. Sensitivity/expertise are conservative suggested triage, not a claim of clinical, legal or security correctness. Review every row in its actual context; test singular/plural and placeholders.
